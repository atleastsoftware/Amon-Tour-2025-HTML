API CONFIGURATION
Endpoint Principal :

GET https://www.tourninja.io/api/public/tours/legacy?companyId=2
Endpoint Sécurisé (optionnel) :

GET https://www.tourninja.io/api/public/tours?apiKey=tourninja-showcase-2-amontour&companyId=2

INTÉGRATION RECOMMANDÉE
Appel API : Récupère les tours toutes les 6 heures
Cache local : Stocke la réponse pour optimiser les performances
Affichage : Utilise primaryImage ou première image du tableau images
Prix : Affiche en THB, gère les prix à 0 (sur demande)
Réservation : Redirige vers bookingUrl pour la réservation
Détails : Redirige vers url pour plus d'informations
GESTION DES ERREURS
Si l'API est indisponible, affiche un message générique
Si price = 0, affiche "Prix sur demande"
Si primaryImage est null, utilise une image par défaut
EXEMPLE CODE FETCH
fetch('https://www.tourninja.io/api/public/tours/legacy?companyId=2')

      // Traiter data.tours

    }
  });
