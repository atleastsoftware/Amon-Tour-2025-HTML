Instructions d'intégration API TourNinja
1. URL de l'API
https://cde80561-c0db-4534-be3c-2648dce69f2c-00-3e1vlysnatw4g.spock.replit.dev/api/public/tours?apiKey=tourninja-showcase-7-amontour&companyId=7
2. Code JavaScript à intégrer
// Code à ajouter dans votre site web
fetch('https://cde80561-c0db-4534-be3c-2648dce69f2c-00-3e1vlysnatw4g.spock.replit.dev/api/public/tours?apiKey=tourninja-showcase-7-amontour&companyId=7')
  .then(response => response.json())
  .then(data => {
    if (data.success) {
      // Créer une section pour afficher les tours
      const toursContainer = document.getElementById('tours-container'); // Vous devez créer cette div
      
      data.tours.forEach(tour => {
        // Créer un élément pour chaque tour
        const tourElement = document.createElement('div');
        tourElement.className = 'tour-item';
        tourElement.innerHTML = `
          <h3><a href="${tour.url}" target="_blank">${tour.name}</a></h3>
          <p>Prix: ${tour.price} ${tour.currency}</p>
          <p>Durée: ${tour.duration} jour(s)</p>
          ${tour.description ? `<p>${tour.description}</p>` : ''}
          ${tour.primaryImage ? `<img src="${tour.primaryImage}" alt="${tour.name}" style="max-width: 200px;">` : ''}
        `;
        
        toursContainer.appendChild(tourElement);
      });
    }
  })
  .catch(error => {
    console.error('Erreur lors du chargement des tours:', error);
  });
3. HTML nécessaire
Ajoutez cette div dans votre page où vous voulez afficher les tours :

<div id="tours-container">
  <!-- Les tours seront ajoutés ici automatiquement -->
</div>

6. Points importants
L'API est publique, aucune authentification spéciale nécessaire
Les liens tour.url mènent vers la page de présentation du tour
Recommandation : Mettez en cache les résultats pendant 6 heures maximum
L'API supporte CORS pour les appels depuis d'autres domaines
