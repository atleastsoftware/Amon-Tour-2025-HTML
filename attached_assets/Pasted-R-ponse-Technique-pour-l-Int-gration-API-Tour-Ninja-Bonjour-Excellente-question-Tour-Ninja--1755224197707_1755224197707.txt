Réponse Technique pour l'Intégration API Tour Ninja

Bonjour,

Excellente question ! Tour Ninja dispose effectivement d'une infrastructure complète pour recevoir des demandes de tours personnalisés via API. Voici la documentation technique pour l'intégration :

API Endpoints Disponibles
1. Endpoint Principal pour Demandes Personnalisées
POST /api/custom-tour-requests
2. Format de Données Accepté
{
  "customerName": "string (requis)",
  "customerEmail": "string (requis, format email)",
  "phone": "string (optionnel)",
  "whatsapp": "string (optionnel)",
  "adults": "number (requis, min: 1)",
  "children": "number (optionnel, défaut: 0)",
  "startDate": "string (requis, format ISO date)",
  "endDate": "string (optionnel)",
  "duration": "number (optionnel, en jours)",
  "interests": ["string"] (optionnel, array d'intérêts),
  "travelTypes": ["string"] (optionnel, ex: ["adventure", "culture", "relaxation"]),
  "destinations": ["string"] (optionnel, destinations souhaitées),
  "message": "string (optionnel, description détaillée)",
  "budget": "number (optionnel)",
  "companyId": "string (requis pour identification)"
}
3. Réponse de Confirmation
{
  "success": true,
  "requestId": "TN-REQ-20250815-ABC123",
  "status": "received",
  "message": "Custom tour request received successfully",
  "estimatedResponseTime": "24-48 hours"
}
4. Endpoint de Suivi de Statut
GET /api/custom-tour-requests/{requestId}/status
Réponse :

{
  "requestId": "TN-REQ-20250815-ABC123",
  "status": "in_progress", // "received", "in_progress", "quoted", "confirmed", "completed"
  "lastUpdate": "2025-08-15T10:30:00Z",
  "assignedAgent": "Agent Name",
  "notes": "Votre demande est en cours de traitement..."
}
Authentification
Header requis : Authorization: Bearer YOUR_API_KEY
Contact Tour Ninja pour obtenir votre clé API spécifique
Champs Obligatoires vs Optionnels
Obligatoires :

customerName
customerEmail
adults
startDate
companyId
Optionnels mais Recommandés :

phone/whatsapp (pour contact direct)
duration
interests
message (description détaillée)
Workflow d'Intégration
Soumission → Demande reçue et validée
Traitement → Assignation à un agent Tour Ninja
Devis → Création d'une proposition personnalisée
Confirmation → Validation client et création du tour
Avantages de l'Intégration
✅ Traitement automatique dans le workflow Tour Ninja
✅ Assignation intelligente aux agents spécialisés
✅ Suivi en temps réel du statut
✅ Génération automatique de devis personnalisés
✅ Intégration avec le système de paiement
✅ Notifications automatiques client/agent
Prochaines Étapes
Demander votre clé API à Tour Ninja
Tester l'endpoint avec vos données
Intégrer le formulaire sur votre site
Configurer le suivi de statut
Cette intégration vous permettra de proposer une expérience client fluide tout en bénéficiant de l'expertise et des outils de gestion avancés de Tour Ninja.
