# Message d'Intégration API pour Amon Tour

## 🎯 Objet : Intégration API Custom Tour Request - Tour Ninja

Bonjour équipe technique d'Amon Tour,

Nous avons développé une **API dédiée** permettant l'intégration directe entre votre site web et notre plateforme Tour Ninja. Cette API vous permet d'envoyer automatiquement les demandes de tours personnalisés de vos clients directement dans notre système de gestion.

## 📋 Informations Techniques d'Intégration

### URL de Production
```
https://www.tourninja.io/api/custom-tour-requests
```

### Authentification
- **Type** : Bearer Token
- **Clé API de test** : `test-api-key-123456789`
- **Header requis** : `Authorization: Bearer YOUR_API_KEY`

### Méthode HTTP
**POST** avec Content-Type: `application/json`

## 💻 Code d'Intégration Prêt à l'Emploi

### Option 1 : JavaScript/AJAX
```javascript
// Exemple d'intégration sur votre formulaire de demande
async function envoyerDemandePersonnalisee(donneesClient) {
    try {
        const response = await fetch('https://www.tourninja.io/api/custom-tour-requests', {
            method: 'POST',
            headers: {
                'Content-Type': 'application/json',
                'Authorization': 'Bearer test-api-key-123456789'
            },
            body: JSON.stringify({
                customerName: donneesClient.nom,
                customerEmail: donneesClient.email,
                phone: donneesClient.telephone,
                whatsapp: donneesClient.whatsapp,
                adults: donneesClient.adultes,
                children: donneesClient.enfants || 0,
                startDate: donneesClient.dateDebut,
                endDate: donneesClient.dateFin,
                duration: donneesClient.duree,
                interests: donneesClient.interets, // Array: ["plages", "culture", "aventure"]
                travelTypes: donneesClient.typesVoyage, // Array: ["famille", "détente"]
                destinations: donneesClient.destinations, // Array: ["Krabi", "Phi Phi"]
                message: donneesClient.message,
                budget: donneesClient.budget,
                companyId: "amontour", // Important : votre identifiant
                sourceApi: "amontour-website"
            })
        });

        const result = await response.json();
        
        if (result.success) {
            console.log('✅ Demande envoyée avec succès !');
            console.log('ID de demande :', result.requestId);
            console.log('Délai estimé :', result.estimatedResponseTime);
            
            // Vous pouvez afficher un message de confirmation à l'utilisateur
            alert(`Demande envoyée avec succès ! 
                   Référence : ${result.requestId}
                   Réponse estimée : ${result.estimatedResponseTime}`);
        }
    } catch (error) {
        console.error('❌ Erreur lors de l\'envoi :', error);
    }
}
```

### Option 2 : PHP (Backend)
```php
<?php
function envoyerDemandeAmonTour($donneesClient) {
    $data = [
        'customerName' => $donneesClient['nom'],
        'customerEmail' => $donneesClient['email'],
        'phone' => $donneesClient['telephone'],
        'whatsapp' => $donneesClient['whatsapp'],
        'adults' => (int)$donneesClient['adultes'],
        'children' => (int)$donneesClient['enfants'] ?: 0,
        'startDate' => $donneesClient['dateDebut'],
        'endDate' => $donneesClient['dateFin'],
        'duration' => (int)$donneesClient['duree'],
        'interests' => $donneesClient['interets'], // Array
        'travelTypes' => $donneesClient['typesVoyage'], // Array
        'destinations' => $donneesClient['destinations'], // Array
        'message' => $donneesClient['message'],
        'budget' => (float)$donneesClient['budget'],
        'companyId' => 'amontour',
        'sourceApi' => 'amontour-website'
    ];

    $options = [
        'http' => [
            'header' => [
                'Content-Type: application/json',
                'Authorization: Bearer test-api-key-123456789'
            ],
            'method' => 'POST',
            'content' => json_encode($data)
        ]
    ];

    $context = stream_context_create($options);
    $result = file_get_contents('https://www.tourninja.io/api/custom-tour-requests', false, $context);
    $response = json_decode($result, true);

    if ($response['success']) {
        return [
            'success' => true,
            'requestId' => $response['requestId'],
            'message' => 'Demande envoyée avec succès !',
            'estimatedTime' => $response['estimatedResponseTime']
        ];
    } else {
        return [
            'success' => false,
            'error' => $response['message']
        ];
    }
}
?>
```

## 📊 Données Requises vs Optionnelles

### ✅ Champs Obligatoires
- `customerName` (string) : Nom complet du client
- `customerEmail` (string) : Email valide
- `adults` (number) : Nombre d'adultes
- `companyId` : "amontour" (votre identifiant)

### 🔧 Champs Optionnels (Recommandés)
- `phone` : Téléphone client
- `whatsapp` : WhatsApp si différent du téléphone
- `children` : Nombre d'enfants
- `startDate` / `endDate` : Dates souhaitées (format ISO)
- `duration` : Durée en jours
- `interests` : Centres d'intérêt (array)
- `travelTypes` : Types de voyage (array)
- `destinations` : Destinations souhaitées (array)
- `message` : Message/demandes spéciales
- `budget` : Budget en euros
- `sourceApi` : "amontour-website"

## 🔍 Vérification du Statut

Vous pouvez vérifier le statut d'une demande :
```javascript
// Vérifier le statut d'une demande
async function verifierStatut(requestId) {
    const response = await fetch(`https://www.tourninja.io/api/custom-tour-requests/${requestId}/status`, {
        headers: {
            'Authorization': 'Bearer test-api-key-123456789'
        }
    });
    
    const status = await response.json();
    console.log('Statut actuel :', status.status);
    console.log('Agent assigné :', status.assignedAgent?.name);
}
```

## 🎯 Statuts de Workflow

- **received** : Demande reçue et en cours d'examen
- **in_progress** : Équipe travaille sur la proposition
- **quoted** : Devis personnalisé préparé
- **confirmed** : Tour personnalisé confirmé
- **completed** : Tour terminé
- **cancelled** : Demande annulée

## 🔒 Sécurité & Production
