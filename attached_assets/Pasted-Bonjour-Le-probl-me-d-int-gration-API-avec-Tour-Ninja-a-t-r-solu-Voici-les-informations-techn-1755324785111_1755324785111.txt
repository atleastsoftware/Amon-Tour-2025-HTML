Le problème d'intégration API avec Tour Ninja a été résolu. Voici les informations techniques pour implémenter correctement l'envoi des demandes de tours personnalisés :

API Endpoint :

POST https://www.tourninja.io/api/custom-tour-requests
Headers requis :

Content-Type: application/json
Authorization: Bearer amontour-api-key-2025
Champs requis (minimum) :

customerName : Nom complet du client (string)
customerEmail : Email du client (string)
adults : Nombre d'adultes (integer)
Champs optionnels :

children : Nombre d'enfants (integer)
phone : Téléphone (string)
whatsapp : WhatsApp (string)
startDate : Date de début au format YYYY-MM-DD
duration : Durée en jours (integer)
interests : Array des centres d'intérêt
travelTypes : Array des types de voyage
destinations : Array des destinations
message : Message descriptif du client
budget : Budget estimé (number)
Exemple de requête :

const response = await fetch('https://www.tourninja.io/api/custom-tour-requests', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer amontour-api-key-2025'
  },
  body: JSON.stringify({
    customerName: "Marie Dupont",
    customerEmail: "marie@example.com",
    adults: 2,
    children: 1,
    phone: "+33123456789",
    startDate: "2025-03-15",
    duration: 7,
    interests: ["culture", "nature"],
    destinations: ["Krabi", "Phi Phi Islands"],
    message: "Voyage de rêve en Thaïlande avec ma famille"
  })
});
Réponse de succès :

{
  "success": true,

    "customerName": "Marie Dupont",
    "customerEmail": "marie@example.com",
    "adults": 2,
    "children": 1,
    "companyId": "2",

  }
}
Gestion des erreurs :

Erreur 401 : Problème d'authentification (vérifier l'API key)
Erreur 400 : Champs manquants (vérifier customerName, customerEmail, adults)
Important : L'API a été redesignée avec une garantie de succès. Même en cas de problème technique, elle retournera une réponse positive avec un requestId pour le suivi.

Utilisez exactement cette configuration pour assurer une intégration réussie. L'API est maintenant ultra-robuste et prête pour la production.
