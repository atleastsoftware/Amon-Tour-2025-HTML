🔄 Chemin de la Requête Widget → Dashboard
1. Front-end (Widget) :
Fichier : client/src/pages/amon-tour-styled.tsx ligne 157
Action : Clic sur bouton "Send Request"
URL Cible : https://www.tourninja.io/api/custom-tour-requests
Méthode : POST
Headers :
Content-Type: application/json
Authorization: Bearer amontour-api-key-2025
2. Backend API :
Fichier : server/routes.ts ligne 8830
Endpoint : POST /api/custom-tour-requests
Authentification : Bearer token vérifié
Validation : Champs obligatoires (customerName, customerEmail, adults)
Table : Sauvegarde dans custom_tour_requests avec companyId = "2"
3. Base de Données :
Table : custom_tour_requests
ID généré : Format TN-REQ-TIMESTAMP-RANDOM
Status : "received"
CompanyId : "2" (Amon Tour)
4. Dashboard (Affichage) :
Fichier : server/routes.ts ligne 2643
Endpoint : GET /api/information-requests
Fusion : Combine bookings (inquiry) + custom_tour_requests
Frontend : client/src/components/InformationRequestsManager.tsx

🎯 Résumé : Chemin Complet Widget → Dashboard
Le flux fonctionne parfaitement :

Widget Amon Tour (https://www.tourninja.io/amon-tour-styled)
⬇️ Clic "Send Request"
⬇️ POST /api/custom-tour-requests avec Bearer token
⬇️ Sauvegarde dans table custom_tour_requests (Company ID "2")
⬇️ Fusion automatique dans /api/information-requests
⬇️ Affichage dans dashboard "Information Requests"

Les demandes du widget s'affichent maintenant directement dans votre dashboard Tour Ninja, section "Information Requests", mélangées avec les autres demandes. Chaque demande reçue via le widget est marquée avec source: "custom_tour_request" pour traçabilité.

Intégration prête : Il suffit d'ajouter l'iframe sur le site Amon Tour pour remplacer le formulaire défaillant.
