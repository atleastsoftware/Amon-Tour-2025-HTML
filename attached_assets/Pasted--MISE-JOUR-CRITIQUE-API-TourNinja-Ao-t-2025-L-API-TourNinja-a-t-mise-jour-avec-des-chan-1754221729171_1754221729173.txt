🚨 Gestion d'Erreurs de Maintenance
Si vous recevez :

{"success":true,"data":[],"message":"Tour Ninja service is temporarily down for maintenance","apiStatus":"server_error"}
Actions à prendre :

Réessayer avec l'API Legacy : /api/public/tours/legacy?companyId=2
Afficher un message : "Nos tours se chargent, veuillez patienter..."
Réessayer toutes les 30 secondes
Si échec persistant, afficher les tours en cache ou message d'indisponibilité temporaire
🔧 Implémentation Immédiate
Mettez à jour votre code JavaScript MAINTENANT :

// Nouvelle logique d'affichage des images
function displayTourImage(tour) {
  return tour.image || '/images/placeholder-tour.jpg';
}
// Nouvelle gestion d'erreurs
async function fetchTours() {
  try {
    const response = await fetch('/api/public/tours?apiKey=tourninja-showcase-2-amontour&companyId=2');
    const data = await response.json();
    
    if (data.apiStatus === 'server_error') {
      // Essayer l'API Legacy
      return await fetchToursLegacy();
    }
    
    return data.tours;
  } catch (error) {
    return await fetchToursLegacy();
  }
}
