💻 CODE D'INTÉGRATION
JavaScript/Fetch :

fetch('https://www.tourninja.io/api/public/tours/legacy?companyId=2')
  .then(response => response.json())
  .then(data => {
    console.log(`${data.tours.length} tours disponibles`);
    data.tours.forEach(tour => {
      console.log(`${tour.name} - ${tour.price} ${tour.currency}`);
    });
  });
PHP/cURL :

$url = 'https://www.tourninja.io/api/public/tours/legacy?companyId=2';
$response = file_get_contents($url);
$data = json_decode($response, true);
foreach ($data['tours'] as $tour) {
    echo $tour['name'] . " - " . $tour['price'] . " " . $tour['currency'] . "\n";
}
